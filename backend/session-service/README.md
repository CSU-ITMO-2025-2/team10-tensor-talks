## session-service — микросервис управления сессиями

`session-service` — простой микросервис для создания и управления сессиями чатов.

### Функциональность

- **POST /sessions** — создание новой сессии для пользователя
  - Принимает: `{ "user_id": "uuid" }`
  - Возвращает: `{ "session_id": "uuid" }`

### Архитектура

Пока это заглушка, которая просто генерирует UUID для сессии. В будущем здесь будет:
- Хранение сессий в БД
- Управление жизненным циклом сессий
- История сессий

### Конфигурация

- `SESSION_SERVER_HOST` — хост сервера (по умолчанию "0.0.0.0")
- `SESSION_SERVER_PORT` — порт сервера (по умолчанию 8083)

### Метрики

- `tensortalks_business_sessions_created_total` — количество созданных сессий
- `tensortalks_http_requests_total` — HTTP запросы
- `tensortalks_http_request_duration_seconds` — длительность HTTP запросов
