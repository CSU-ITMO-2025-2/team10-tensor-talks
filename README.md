## 📋 О проекте

**TensorTalks** — это AI-симулятор технических интервью в области машинного обучения. Платформа помогает ML-специалистам готовиться к собеседованиям с помощью AI-интервьюера и предоставляет объективную оценку компетенций.

### 🎯 Основная идея

TensorTalks помогает:
- 🤖 **ML-специалистам** готовиться к техническим интервью
- 📊 **Компаниям** объективно оценивать кандидатов
- 📈 **HR и TechLead** стандартизировать процесс найма
- 🎯 **Командам** развивать компетенции сотрудников

## 🚀 Быстрый старт

```bash
# Клонируйте репозиторий
git clone https://github.com/PaulRychkov/TensorTalks.git
cd TensorTalks/frontend

# Установите зависимости
npm install

# Запустите dev сервер
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.
